# Release Notes

## Microsoft.SqlServer.TransactSql.ScriptDom 180.140.0
This update brings the following changes over the previous release:

### Target Platform Support

* .NET Framework 4.7.2 (Windows x86, Windows x64)
* .NET 8 (Windows x86, Windows x64, Linux, macOS)
* .NET Standard 2.0+ (Windows x86, Windows x64, Linux, macOS)

### Dependencies
* None

#### .NET Framework
#### .NET Core

### New Features
* Adds `ON ERROR` clause support (`ERROR`, `NULL`, and `DEFAULT`) for Fabric DW AI functions: `AI_ANALYZE_SENTIMENT`, `AI_CLASSIFY`, `AI_EXTRACT`, `AI_FIX_GRAMMAR`, `AI_GENERATE_RESPONSE`, `AI_SUMMARIZE`, and `AI_TRANSLATE`.
* Adds Fabric DW join hints (`REPLICATE` and `REDISTRIBUTE`) and query hints, including `FORCE SINGLE NODE PLAN`, `FORCE DISTRIBUTED PLAN`, and `FOR TIMESTAMP AS OF`.

### Fixed
* Fixes parsing of bracketed and double-quoted named `WINDOW` references in SQL Server 2022 and later.
* Fixes lexer handling of U+FFFF in string literals, delimited identifiers, and comments so it is not treated as end-of-input.
* Fixes source-token ranges for `GROUP BY ALL` in the Fabric DW parser.
* Fixes `ColumnAliasStyle.Preserve` so it retains whether a SELECT column alias used the `AS` keyword.
* Fixes preserved comment ordering and placement around comma-separated lists, before `FROM`, and in stored procedure parameters.
